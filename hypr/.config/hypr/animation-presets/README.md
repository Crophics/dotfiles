# Animation presets

`snappy` is this setup's own animation set (in `look.lua`). The other files here come from the
[ML4W dotfiles](https://github.com/mylinuxforwork/dotfiles) (GPL-3.0), which in turn collect the
Material-style curves popularised by end-4's setup and the Hyprland wiki examples. They are used
unchanged apart from a short header. Pick one in Settings > Windows > Animation style.
